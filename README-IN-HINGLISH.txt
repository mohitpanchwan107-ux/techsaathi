IMPORTANT CATALOGUE NOTES
- The homepage currently has 30 catalogue entries.
- Some cards describe product families rather than one exact model.
- Many cards use clearly labelled illustrative category previews, not verified photos of the exact product.
- Retailer links currently open search results, not guaranteed exact product listings.
- Product prices, stock, variants and specifications can change. Verify them on the official product page before purchase.
- New products do not automatically appear. A reliable product feed/API and a maintenance process would be needed for automation.
- No affiliate earnings are claimed unless a link is clearly labelled as an affiliate link.

PUBLISHING
The site is hosted by GitHub Pages. Commits to the configured publishing branch update the source, but deployment can take a short time. Check the Actions/Pages deployment status and then test the live URL.

BEFORE CALLING THE SITE FULLY FINAL
1. Test the homepage on desktop and mobile.
2. Test every search/filter, details popup, manufacturer link and retailer search.
3. Check all product image URLs; replace category previews with verified exact product images where desired.
4. Confirm all page links, sitemap.xml, robots.txt and 404 behaviour.
5. Set up Google Search Console and submit the sitemap.
6. Revisit this README whenever catalogue data or site features change.
