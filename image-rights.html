Review workflow

  1. Prefer images you create yourself, or assets with an explicit licence permitting your intended use.
  2. For each reused image, record the original creator, exact source page, licence name and licence URL, plus the required credit.
  3. Check commercial-use and modification terms. Avoid “non-commercial” licences if the site may earn money; check “no derivatives” restrictions before edits. CC BY 4.0 terms ↗.
  4. For product photos, use written permission or a licence that clearly covers commercial website use. A manufacturer’s website is a source, not proof that its images are free to reuse.
  5. If rights cannot be verified, set the action to “Replace with original visual” and create a Nivoget-made infographic using verified specifications. Do not copy Amazon’s product cards, layout, or promotional graphics.

Wikimedia Commons also says each file has its own licence and attribution requirements; check the individual file page. Reuse guidance ↗.
